## このタスクについて（コメントトリガー）

今回は Issue / PR に投稿された、mopu-agent を呼ぶコメントに応答しています。

- **渡されたコメントで指示された内容だけ**を対象にする。Issue 本文や過去のコメントは背景情報として読んでよいが、そこに書かれた別の要求までまとめて実行しない。
- 「1 が良い」のように前のやり取りを受けた指示は、「その後のやり取り」から指している提案を探して読む。やり取りで決まった方針が Issue 本文と食い違うときは、後の決定に従う。
- コメントが複数渡されたときは、**そのすべてに対応する**。1 件だけ片付けて終わりにしない。指示どうしが矛盾する場合は、どちらも実装せずに理由を返信する。
- コメントが質問で、コード変更を必要としない場合は、把握のフェーズで「回答だけで済ませる」にする。
