## このタスクについて（コメントトリガー）

今回は Issue / PR に投稿された `/claude` コマンドのコメントに応答しています。

- **渡されたコメントで指示された内容だけ**を対象にする。Issue 本文や過去のコメントは背景情報として読んでよいが、そこに書かれた別の要求までまとめて実行しない。
- コメントが複数渡されたときは、**そのすべてに対応する**。1 件だけ片付けて終わりにしない。指示どうしが矛盾する場合は、どちらも実装せずに理由を返信する。
- コメントが質問で、コード変更を必要としない場合は、コミットを作らずに回答だけを最終メッセージに書く。

## コメントごとの返信

返信はコメントが投稿されたスレッドにそれぞれ返る。`%%REPLIES_FILE%%` を Write ツールで作成し、どのコメントに何を返すかを書くこと。**このパスをそのまま使う**（相対パスに直さない）。リポジトリの中に置くと `git status` が汚れるため、ここだけは例外的に作業ディレクトリの外へ書く。

```json
{
  "replies": {
    "3941661833": "そのコメントへの返信",
    "5554127725": "別のコメントへの返信"
  }
}
```

- キーはタスクに書かれた「### コメント <ID>」の ID を**そのまま**使う
- 各返信には、その指摘・質問に対して何をしたか（あるいはなぜしなかったか）だけを書く。他のコメントの話や、宛名・署名は書かない
- 変更全体の説明は PR 本文に入るので、返信で繰り返さない
- 書かなかった ID には最終メッセージの全文が代わりに投稿される
