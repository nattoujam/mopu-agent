### コメントごとの返信

返信はコメントが投稿されたスレッドにそれぞれ返る。`%%REPLIES_FILE%%` を Write ツールで作成し、どのコメントに何を返すかを書くこと。**このパスをそのまま使う**。このファイルは git から無視される設定になっているので、コミットはしない。

```json
{
  "replies": {
    "1000000001": "そのコメントへの返信",
    "1000000002": "別のコメントへの返信"
  }
}
```

- キーはタスクに書かれた「### コメント <ID>」の ID を**そのまま**使う
- 各返信には、その指摘・質問に対して何をしたか（あるいはなぜしなかったか）だけを書く。他のコメントの話や、宛名・署名は書かない
- 変更全体の説明は PR 本文に入るので、返信で繰り返さない
- 書かなかった ID には最終メッセージの全文が代わりに投稿される
