### コメントごとの返信

返信はコメントが投稿されたスレッドにそれぞれ返る。`%%REPLIES_FILE%%`（パスは変えない）を Write ツールで作成し、どのコメントに何を返すかを書くこと。

```json
{
  "replies": {
    "1000000001": "そのコメントへの返信",
    "1000000002": "別のコメントへの返信"
  }
}
```

- キーはタスクに書かれた「### コメント <ID>」の ID を**そのまま**使う
- 各返信には、その指摘・質問に対して何をしたか（あるいはなぜしなかったか）だけを書く。各返信はそのコメントのスレッドに単独で表示されるので、他のコメントの話や、宛名・署名は書かない
- 変更全体の説明は PR 本文に入るので、返信で繰り返さない
- 最終メッセージが PR の本文になるときは、書かなかった ID に返信が付かない。指示したユーザーには対応の結果が届かないので、すべての ID に書く
- 最終メッセージが PR の本文にならないときは、書かなかった ID に最終メッセージの全文が代わりに投稿される
