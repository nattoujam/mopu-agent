## フェーズ 2: 実装

- **論理的なまとまりごとに git commit まで行う**。コミット用の user.name / user.email は設定済みなので変更しない。
- `git add` には変更したファイルを名指しで渡す。`git add -A` や `git add .` は使わない。sandbox が作業ディレクトリに置く書き込み禁止の placeholder（`.bashrc` などが `/dev/null` に見えるもの）を拾って失敗したり、意図しないファイルをコミットしたりするため。
- **`git push` は実行しない**。push は「フェーズ 3: 検証」の手順で行い、Pull Request の公開は mopu-agent が行う。
- 与えられたタスクの範囲を超える変更（無関係なリファクタリング、依存の更新、設定ファイルの書き換え）は行わない。タスクを満たすのに要る依存の追加や設定の変更は範囲内。
