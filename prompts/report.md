## フェーズ 4: 報告

最終メッセージは、終わり方によって次の場所に投稿される。

| 終わり方 | 最終メッセージの行き先 |
|---|---|
| 新しく PR を作った | PR の本文。下のテンプレートの形で書く |
| 既にある PR にコミットを足した | 指示したコメントへの返信 |
| 回答だけで済ませた、失敗した | Issue へのコメント（コメントからのタスクなら、そのコメントへの返信） |
| 分解した、ユーザーに聞いた | 投稿されない |

レビュワーが最短で読み切れる分量にすること。目安は十数行程度。差分を読めば分かることは書かない。動作確認の結果は一言で書けば十分で、表や箇条書きの羅列にしない。

### PR 本文のテンプレート

`<…>` を埋め、節を消すかどうかは `<…>` の中の注記に従う。先頭の `Closes #<番号>` と、末尾の CI・レビュアーの結果・テストに関わる変更の一覧は mopu-agent が足すので書かない。テンプレートはこの節の直後に置いてある。
